# Модели требований сайта jaiora.me (Quint)

Правило Jaiora: любое изменение поведения или интерфейса — сначала требование и модель Quint, отдельным коммитом, потом
код. `current` — код как есть, `fixed` — требование. Прогон: `npm run quint` (= `bash quint/run.sh`), правила —
`PRACTICES.md`, заготовка — `TEMPLATE.qnt` (общие с youtube-broadcaster). Тексты страниц («понятно ли», «красиво ли»)
не моделируются — сверка с Егором.

| Код | Требование | Модель |
|---|---|---|
| Пс1 | Открытие страницы не отдаёт данные посетителя никому, кроме размещения сайта (шрифты — с самого сайта) | site_privacy `onlyHosting` |
| Пс2 | У сайта нет cookie и счётчиков посещений | site_privacy `noTracking` |
| Пс3 | Политика конфиденциальности содержит все обязательные пункты: права (включая жалобу в орган по защите данных), основу передачи в другие страны, то, что данные ботов Jaiora обрабатывает Jaiora | site_privacy `policyComplete` |
| Пс4 | Всё, что политика обещает про сайт, — правда | site_privacy `promisesTrue` |
